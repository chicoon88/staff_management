이번 달 연차 발생 직원

연차는 시간으로 관리합니다. 주5일은 1년 미만 월 +8h, 주4일(주32h 소정)은 월 +7h가 기본이며, 스케줄에 ‘연’을 입력하면 8h 차감합니다.

운영 흐름

① 월간 스케줄 작성 → ② 실제 근무시간 필요 시 날짜 클릭해 수정 → ③ 월 근로시간 확인 → ④ 노무사 급여대장 Excel 업로드 → ⑤ 스케줄 시간과 급여대장 시간 차이 검수 → ⑥ 필요 시 스케줄/급여 Excel 출력.

월간 스케줄

빠른 입력은 8 / 9 / 0 / 연 / 병, 세부 시간은 날짜 셀을 두 번 누르거나 상세수정 버튼을 이용하세요.
저장완료
먼저 직원명 왼쪽 체크박스 선택8 = 8시간9 = 8시간+연장10 = 휴무연 = 연차병 = 병가숫자 직접입력 가능
※ 직원마다 기본 출퇴근시간·휴게시간·근무요일을 따로 설정할 수 있습니다. 예외 근무는 날짜 셀의 ‘상세’에서 그날만 변경합니다.

급여 · 지급관리

과거 실제지급 · 현재 예상 · 수기확정 · 인센 발생월을 따로 관리합니다.
관리 방식
지급완료는 빨간색, 예상/미지급은 검정색으로 표시합니다. 자동예상은 빈 값만 만들며 수기입력·지급완료 값은 덮어쓰지 않습니다.
월급직원: 기본 근무분은 익월 10일 지급 / 인센 발생횟수는 실제 근무월에 기록하고 기본값으로 2개월 뒤 지급분에 반영. 파트타임은 당월 말일 지급.
기존 약국급여표를 가져오면 과거 금액·인센횟수와 빨강/검정 상태를 읽습니다.
