이번 달 연차 발생 직원

연차는 시간으로 관리합니다. 주5일은 1년 미만 월 +8h, 주4일(주32h 소정)은 월 +7h가 기본이며, 스케줄에 ‘연’을 입력하면 8h 차감합니다.

운영 흐름

① 월간 스케줄 작성 → ② 실제 근무시간 필요 시 날짜 클릭해 수정 → ③ 월 근로시간 확인 → ④ 노무사 급여대장 Excel 업로드 → ⑤ 스케줄 시간과 급여대장 시간 차이 검수 → ⑥ 필요 시 스케줄/급여 Excel 출력.

월간 스케줄

빠른 입력은 8 / 9 / 0 / 연 / 병, 세부 시간은 날짜 셀을 두 번 누르거나 상세수정 버튼을 이용하세요.
준비저장완료연차잔여는 입력 즉시 반영
먼저 직원명 왼쪽 체크박스 선택8 = 8시간9 = 8시간+연장10 = 휴무연 = 연차병 = 병가숫자 직접입력 가능공휴일: 날짜 빨강 + 공휴일명 표시
※ 직원마다 기본 출퇴근시간·휴게시간·근무요일을 따로 설정할 수 있습니다. 예외 근무는 날짜 셀의 ‘상세’에서 그날만 변경합니다.

직원관리

근로자현황 또는 약국급여표 Excel을 올리면 직원 후보를 자동으로 찾아 등록합니다.
직원은 한 번만 등록하면 됩니다. 과거월은 입사일·퇴사일로 자동 판별합니다.
지원 파일: 근로자현황파악 / 약국급여표. 파일 구조를 자동판별해 성명·입사일(근무시작일)·직무 등을 가져옵니다. 근무조건이 없는 직원은 등록 후 ‘확인 필요’로 표시합니다. 주민번호·계좌번호는 현재 직원 자동등록에서는 저장하지 않습니다. 애매한 행은 ‘확인 필요’로 표시합니다.
연번은 현재 직원순서에 따라 자동 생성됩니다. ↑/↓로 순서만 바꾸면 연번도 자동 재정렬됩니다.
연번이름업무입사일퇴사일근무형태기본시간휴게스케줄방식급여형태연차 기준연차 잔여급여 지급규칙순서출력색문서

업장관리

업장명뿐 아니라 사업자번호·대표자·주소·전화번호를 저장하면 증명서에 자동 반영됩니다.

공휴일 관리

대한민국 공휴일은 연도별로 자동 불러옵니다. 공휴일은 주말보다 우선하며, 필요한 경우에만 수동 추가할 수 있습니다.
